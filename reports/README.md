# Reports

This directory contains the curated, version-controlled outputs of the reference run.

| File | Description |
|---|---|
| `v2_report.md` | Full research report generated by the pipeline |
| `metrics.csv` | Full out-of-sample metrics for every model |
| `holdout_metrics.csv` | Confirmatory holdout metrics |
| `decision_sensitivity.csv` | Risk-aversion, position-cap, and covariance-scale sensitivity |
| `forecast_ic.csv` | Cross-sectional information coefficient by model |
| `moe_stability.json` | Restart-stability audit on 24 training windows |
| `red_team_checks.json` | Publication-gate checks: cost sensitivity, gross/net uncertainty, IC HAC/bootstrap |
| `red_team_cost_sensitivity.csv` | Holdout net Sharpe by cost assumption |
| `figures/` | Cumulative wealth, drawdowns, rolling Sharpe, weights, gating, PIT |

The authoritative run artifacts, including the manifest and per-model files, are in `runs/reference/`. `runs/` is git-ignored because it contains the full data snapshot and binary covariance arrays.

Do not edit `v2_report.md` by hand. Re-run:

```bash
python -m moe_factor_timing run --config configs/default.yaml --run-id reference --publish
```

The report is generated from the same objects that produce the metrics. A hand edit would break that link.
